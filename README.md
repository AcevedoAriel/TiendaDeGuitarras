# 🎸 Tienda de Guitarras - Proyecto Taller I

¡Bienvenido/a! Este es el repositorio de nuestra plataforma de comercio electrónico dedicada a la venta de guitarras eléctricas, acústicas y accesorios musicales.

## 🚀 Características del Proyecto
* 🛒 Catálogo completo de instrumentos musicales.
* 🔍 Filtros por tipo de guitarra (Eléctricas, Acústicas, Criollas).
* 📱 Interfaz adaptable para dispositivos móviles y computadoras.

## 🛠️ Tecnologías Utilizadas
* **Framework Backend:** CodeIgniter 4 (PHP)
* **Servidor Local:** XAMPP (Apache y MySQL)
* **Frontend:** HTML5, CSS3 y JavaScript

## 📦 Cómo ejecutarlo localmente
1. Clona este repositorio en tu carpeta `htdocs` de XAMPP:
   ```bash
   git clone https://github.com/AcevedoAriel/TiendaDeGuitarras.git
   ```
2. Activa **Apache** y **MySQL** desde el panel de XAMPP.
3. Importa la base de datos *(si utilizas una)*.
4. Abre tu navegador e ingresa a: `http://localhost/CI_AcevedoAriel/public/`
